touch command - made for updating the access and the timeStamp of the file but generally used to create a/more new file(s)

Basic syntax - touch fileName.extension

mkdir command - used to create a new directory

move command - either used to move a file/directory from one place to another or simply rename the file

1. to rename a file
mv intitalName.extension finalName.extension

2. Moving a file from the current directory to another nested directory:
mv report.csv archives/report.csv

3. Moving a file from the current directory, to the parent directory:
mv invoice.pdf ../invoice.pdf

4. If you don't want to rename the file and you're just moving it to a different directory, you can omit the filename:
mv photo.png images/
