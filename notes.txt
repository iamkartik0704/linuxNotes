echo is used for printing a stmt
example: echo "Hi I am Pi"

a terminal is a program that accepts text based commands and can render text on screen

shell is the program that runs the terminal commands ie main job is to interpret the commands you type and execute them.

shells are basically referred to as REPL- read evaluate print loop

expr command is used to evaluate and print the expression
example:- expr 420-69
output:- 420-69 (without spaces it is considered a single expr)

example:- expr 420 - 69
output:- 351

whoami :- prints the username of  the user you are currently logged in as.

directories refer to the folders    
root directory is the topmost folder in the heirarchy

pwd is used to print the current directories' name
(say it returns /home/users - the first '/' represents the root directory and home is the directory inside root and users is inside home ) so the heirarchy follows:-
folder structure tree

root
    |->home
          |-> users

ls command is used to print the content of a directory

cd command is used to change the directory 
cd .. takes you to one level above in the heirarchy

absolute and relative path
absolute- starts from the root of the fileSystem (in linux root is denoted by '/') - prefer this when you are unaware of the directory you wish to work in

relative - here the path is relative to the directory you are working in rn and it doesn't start with '/'

cat command - used to view the content inside a/multiple files

head command - used to print the first n lines of the code
syntax - head -n 10 files.txt   (bydefault 10)

similar to the head command, we have the tail command;
tail command - used to print the last n lines of the code
syntax - tail -n 10 files.txt
