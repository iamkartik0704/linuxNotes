#Permissions
In Linux, every single file and directory is assigned two things regarding ownership:
An Owner (a specific individual user).
A Group (a designated collection of users).
the Permissions are usually defined by 10 char string

the first char: "D" for directory or "-" for a file
then there exist 3 sets of Permissions for :
1. owner
2. Group
3. others

each set looks like r w x where r stands for read Permission , w for write Permission and x for execute Permission


chmod
used to change the Permission of a file or directory
use -r flag to assign the Permission recursively

basic syntax: chmod -R u=rwx,g=,o= DIRECTORY
u stands for the owner , g for the group and o for others
since here g nd o are assigned nothing, they got no Permissions
DIRECTORY/FILE
for a file do not use -R

chmod +x is used to grant the executable Permission to the script to help it get download
