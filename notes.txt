touch command - made for updating the access and the timeStamp of the file but generally used to create a/more new file(s)

Basic syntax - touch fileName.extension

mkdir command - used to create a new directory

move command - either used to move a file/directory from one place to another or simply rename the file

1. to rename a file
mv intitalName.extension finalName.extension

2. Moving a file from the current directory to another nested directory:
mv report.csv archives/report.csv

3. Moving a file from the current directory, to the parent directory:
mv invoice.pdf ../invoice.pdf

4. If you don't want to rename the file and you're just moving it to a different directory, you can omit the filename:
mv photo.png images/

grep command:
The most basic use for grep is to search for a string(case sensitive) in a file
basic syntax:- grep "string" filePath

you can also use it to find the content in multiple files
basic syntax - grep "string" filePath1 filePath2

grep -r "hello" .
this is used to recursively find the word "hello" in the current directory and its subdirectories

grep used to search for the file content and not the file name
find command: allows you to look for a specific file in a particular directory
basic syntax: find some_directory -name hello.txt

it also allows pattern searches, say i want to look for all the txt files then:
find some_directory -name "*.txt"

find some_directory -name "*kartik*"
this helps to find all the files with the name "kartik" in it

to look for something in the current directory 
find . -name "*kartik*"
